How I work

From ambiguous problem to measured outcome.

Most of my enterprise work started as a vague complaint from a client or a support queue. This is the loop I use to turn it into a product decision.

1

Discover

Talk to the people who feel the friction. Map the request volume, escalations, and where time is lost.

2

Scope

Define the user, the smallest useful feature, and what is out of scope. Write the PRD before the build starts.

3

Prioritize

Rank the backlog by user impact, SLA risk, and engineering cost. Protect the work that keeps commitments.

4

Measure

Set the KPI before launch. Track it after. Use evaluation rubrics for AI features so quality is visible.
